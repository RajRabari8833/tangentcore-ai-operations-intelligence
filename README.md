# TangentCore — AI Operations Intelligence

A frontend-only operations dashboard prototype built with React and Vite. It presents service health, incident tracking, operational KPIs, and simulated AI recommendations using browser-side sample data.

## Features
- Operations overview and KPI cards
- Search services and incidents
- Service health and latency indicators
- Filter incidents by severity
- Mark incidents as resolved
- Simulated AI recommendations with acknowledge/dismiss actions
- Export incident list as CSV
- Responsive sidebar and mobile layout
- No backend, API, or database required

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown in the terminal.

## Production build
Run `npm run build`, then `npm run preview`.

## Tech
React, Vite, JavaScript, CSS, Lucide React.

## Important
This is a portfolio UI prototype. Metrics and recommendations are illustrative sample data; it does not connect to real infrastructure or make real AI/API calls.
